# HTTP 403 — Authenticated Without Required Role

## Purpose

Confirm that authentication alone does not grant protected API access.

## Preconditions

- The roleless child Agent Identity can complete T1 and T2.
- Conditional Access is not blocking this child's T2 exchange during this scenario.
- The child does not have `Investigation.Read`.

## Expected result

| Field | Expected value |
|---|---|
| T1 | Succeeds |
| T2 | Succeeds |
| `Investigation.Read` | Absent |
| API reached | Yes |
| HTTP status | 403 |

## Interpretation

The child identity authenticated and obtained the protected API token, but the API enforced least privilege because the required application role was missing.

Do not describe this HTTP 403 as a Conditional Access block.
