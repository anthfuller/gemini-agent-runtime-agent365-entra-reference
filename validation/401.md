# HTTP 401 — Missing Bearer Token

## Purpose

Confirm that the protected API rejects an unauthenticated request.

## Request

```bash
curl -i "${PROTECTED_API_BASE_URL}/investigations/LAB-001"
```

Do not include an `Authorization` header.

## Expected result

| Field | Expected value |
|---|---|
| API reached | Yes |
| HTTP status | 401 |
| Safe response | Missing bearer token |

## Interpretation

The protected API rejected the request before application-role evaluation. This does not exercise T1, T2, or Conditional Access.

Retain only the status and sanitized response. Do not include environment-specific URLs in published evidence.
